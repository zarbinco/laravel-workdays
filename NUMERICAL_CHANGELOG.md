This reference records observed older outputs, current contracts and the exact tests that protect them. Config and Database each supply one complete pinned view. Date-only calendars, recurrence, cutoff eligibility and business-day transit retain distinct policies. All counts in the historical evidence sections are prior executions, not new documentation-task results.

## Boundary And Compatibility Evidence

The older implementation contained `WorkingHours::hasEnhancedConfig`, calculator enhanced arithmetic/boundary branches, per-window/per-day minute truncation, one-second previous navigation, elapsed-midnight materialization, reverse mode/capacity branches and mode-dependent snapshot windows. The historical failing cases above demonstrate the observable differences. Current `EffectiveWorkingHours`, `WorkingTimeBoundary` and `WorkingTime` provide one selection/materialization/interval arithmetic path. Removed methods are not hidden behind a compatibility flag.

The preliminary full run exposed three remaining inheritance fixtures encoding the discarded `11:01` rounding (2,131 tests / 8,162 assertions, three failures). Current expectations use exact elapsed time, including total difference `0 → 1`. `DynamicProfilesTest::test_inherited_false_only_flag_uses_the_same_exact_precision_as_other_schedules` names the corrected inherited contract; its whole 138-case suite then passed 275 assertions. These failures are intentional numerical-anchor updates, separate from regressions in inheritance ownership.

Historical review also executed 16 runtime-metadata-drift cases: eight one-microsecond work-result corruptions were incorrectly accepted while eight valid controls restored. Final restoration validates every work/handoff result through the shared engine over captured UTC intervals. Matching tzdb additionally replays the full frozen rules/plan regardless of PHP/Carbon/Verta/Islamic version drift. Different tzdb still enforces UTC work/handoff consistency plus structural/transit-microsecond checks; rederiving historical civil-date transit choices requires the unavailable historical tzdb. `UnifiedSnapshotSlaTest::test_runtime_drift_cannot_hide_one_microsecond_work_result_corruption`, `test_valid_current_semantics_work_snapshot_remains_portable_across_runtime_metadata_drift`, and `test_historical_tzdb_handoff_and_day_transit_keep_strict_portable_result_checks` cover corrupt and valid controls. No old arithmetic or schema change was introduced.

Historical isolated Laravel 12 highest/lowest runs each reached 2,158 tests / 8,243 assertions with two diagnostic-substring failures: earlier shared-UTC consistency checks now rejected the intended corruptions before the old full-plan replay check. The established `original result is inconsistent` diagnostic wording was preserved in production; both protected existing assertions remained unchanged. Failing logs were retained separately before the final full reruns. The same tamper rejection remains observable through its established diagnostic.

Historical offset changes can move backward across a civil-date label, beyond an ordinary repeated hour. Core difference/navigation/addition now fail contextually when that split history cannot be represented, rather than returning a partial zero total. `UnifiedWorkingTimeBoundaryTest::test_split_civil_date_histories_fail_explicitly_instead_of_returning_partial_accounting` covers StJohns/GooseBay1988 in both sources and all relevant methods; `test_an_ordinary_repeated_hour_remains_representable_with_exact_elapsed_capacity` retains valid fold accounting. The final default suite and both isolated Laravel12 full suites each passed **2,158 tests / 8,243 assertions**; local MySQL passed **7 / 92**. PHP8.2/8.4 and remote CI remain external execution gates, not claimed passes.

Calendar-first exact/seasonal/weekly/fallback precedence, explicit empty inheritance distinctions, day-only usability, Gregorian/Jalali/Hijri, source routing, raw immutable publications, CAS/transactions/races, import/export, the Iran explicit-clear guard and typed result families remain. The importer/repository/schema are not rewritten to normalize schedules. Boundary/source/overflow/programming failures remain explicit; a shared typed search-exhaustion exception preserves Bulk's accepted domain-error classification at its trusted package origin. No new public subtraction/fractional-minute API, dependency, UI, automatic job or data migration is introduced.
